Docker Container Architecture & Commands

Quick reference for container deployment commands and networking architecture.

🔗 Port Mapping Mechanism (-p 8080:80)

Containers run in isolated network namespaces. The -p flag creates a tunnel from your host machine into the container:

Host (MacBook)
Port 8080
http://localhost:8080
↔ Docker Engine Bridge ↔ -p 8080:80
Nginx Container
Port 80
/usr/share/nginx/html
Rule: -p [HOST_PORT]:[CONTAINER_PORT]. Traffic hitting localhost:8080 is forwarded directly to Nginx listening on port 80.

⚡ Essential Container Commands

Build Docker Image docker build -t devops-project-4:v1 .
Run Container (Detached + Port Map) docker run -d --name devops-project-4 -p 8080:80 devops-project-4:v1
Inspect Live Logs docker logs -f devops-project-4
Stop & Remove Container docker stop devops-project-4 && docker rm devops-project-4
